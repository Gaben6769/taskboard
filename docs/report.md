## Git

У репозиторії `taskboard` стартові файли відстежуються в гілці `main`. Команда `git add` додає вибрані зміни до індексу, `git commit` фіксує їх зі змістовним повідомленням, а `git log --oneline --graph --all` показує історію. Правила в `.gitignore` виключають локальні налаштування, кеш Python і журнали.

Гілки дають змогу перевіряти кожну частину проєкту окремо. `git switch -c` створює гілку та перемикає на неї, а `git merge --no-ff` зберігає в історії момент локального злиття.
