## Git

У репозиторії `taskboard` стартові файли відстежуються в гілці `main`. Команда `git add` додає вибрані зміни до індексу, `git commit` фіксує їх зі змістовним повідомленням, а `git log --oneline --graph --all` показує історію. Правила в `.gitignore` виключають локальні налаштування, кеш Python і журнали.

Гілки дають змогу перевіряти кожну частину проєкту окремо. `git switch -c` створює гілку та перемикає на неї, а `git merge --no-ff` зберігає в історії момент локального злиття.

## W-07 · Семантичний HTML

Семантичні теги описують роль вмісту. Завдяки цьому браузер і програми читання з екрана можуть розпізнати навігацію та перейти до основного вмісту. Універсальний `div` використано там, де потрібна обгортка для групування елементів.

У розмітці використано `header`, `nav`, `main`, `section`, `article`, `footer`, `figure`, `figcaption`, `ul`, `li`, `table`, `thead`, `tbody`, `th` і `td`.

## W-10 · Flexbox і форма

`flex-wrap: wrap` переносить елементи в новий рядок, якщо вони не вміщуються. Медіа-запит до 600 px складає шапку, профіль і поля форми у стовпчик та розтягує кнопку на всю ширину.

`name` визначає ключ поля під час зчитування даних форми, а `id` дає JavaScript змогу знайти конкретний елемент у DOM. Вкладені підписи `label` полегшують фокусування і пояснюють призначення кожного поля.
