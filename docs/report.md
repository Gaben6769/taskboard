## Git

У репозиторії `taskboard` стартові файли відстежуються в гілці `main`. Команда `git add` додає вибрані зміни до індексу, `git commit` фіксує їх зі змістовним повідомленням, а `git log --oneline --graph --all` показує історію. Правила в `.gitignore` виключають локальні налаштування, кеш Python і журнали.

Гілки дають змогу перевіряти кожну частину проєкту окремо. `git switch -c` створює гілку та перемикає на неї, а `git merge --no-ff` зберігає в історії момент локального злиття.

## W-07 · Семантичний HTML

Семантичні теги описують роль вмісту. Завдяки цьому браузер і програми читання з екрана можуть розпізнати навігацію та перейти до основного вмісту. Універсальний `div` використано там, де потрібна обгортка для групування елементів.

У розмітці використано `header`, `nav`, `main`, `section`, `article`, `footer`, `figure`, `figcaption`, `ul`, `li`, `table`, `thead`, `tbody`, `th` і `td`.

## W-10 · Flexbox і форма

`flex-wrap: wrap` переносить елементи в новий рядок, якщо вони не вміщуються. Медіа-запит до 600 px складає шапку, профіль і поля форми у стовпчик та розтягує кнопку на всю ширину.

`name` визначає ключ поля під час зчитування даних форми, а `id` дає JavaScript змогу знайти конкретний елемент у DOM. Вкладені підписи `label` полегшують фокусування і пояснюють призначення кожного поля.

## W-12 · JavaScript і DOM

Обробники змінюють масив `tasks`, а функція `render()` створює елементи списку з актуальних даних та оновлює лічильник. `preventDefault()` зупиняє стандартне надсилання форми, щоб сторінка залишалася відкритою. `textContent` показує назву та опис як звичайний текст, навіть якщо вони містять HTML-теги.

Один обробник кліків на списку знаходить елемент задачі через `closest()` і читає її ID з `dataset`. Після кожної зміни оновлений масив записується у `localStorage` під ключем `taskboard.tasks`. При відкритті сторінки застосунок завантажує цей масив і знову викликає `render()`.

| Зміна для перевірки | Результат тесту JavaScript | Виправлення |
| --- | --- | --- |
| Селектор `#task-from` | Скрипт отримав `null` і зупинився з `TypeError` при виклику `addEventListener`. | Повернути `#task-form`. |
| Прибрати `preventDefault()` | Подія форми лишилась без скасування. У браузері діятиме стандартне надсилання. | Повернути `event.preventDefault()` на початок обробника. |
| Пропустити `render()` після додавання | У сховищі з’явилася задача, але список лишився порожнім. | Викликати `render()` після збереження. |

У Chrome перевірено перехід між сторінками, відхилення назви з пробілів, додавання двох задач, лічильник, відмітку виконання, видалення та відновлення списку після оновлення. У режимі iPhone 16 (393 CSS px) поля форми розташовані в стовпчик, а кнопка займає всю їхню ширину.
